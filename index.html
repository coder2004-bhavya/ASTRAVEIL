MISSION BRIEF // ASTRAVEIL

PROJECT OVERVIEW

ASTRAVEIL is a proof-of-concept Space & Defence Situational Awareness platform developed as a Level 4 internship showcase project for DRDO recruitment evaluation.

TECHNICAL ARCHITECTURE

Built on Three.js for 3D rendering, Globe.gl for interactive orbital visualization, and satellite.js for real-time TLE propagation. All satellite positional data is sourced live from CelesTrak's public API — the same data used by aerospace organizations worldwide.

DRDO RELEVANCE

  • ISSA: Integrated Space Situational Awareness — debris tracking and conjunction analysis
  • MRSAM: Medium-Range Surface-to-Air Missile — trajectory and intercept modeling
  • ASAT: Anti-Satellite capability — LEO target simulation
  • IRNSS: Indian Regional Navigation Satellite System — constellation visualization

DATA SOURCES

CelesTrak (celestrak.org) — Free public TLE data updated every 8 hours. Used by NASA, ESA, and commercial operators for collision avoidance.

MODULE 02 // COLLISION RISK ANALYSIS

CONJUNCTION DATA MESSAGE

Collision risk is calculated using a simplified version of NASA's CARA (Conjunction Assessment Risk Analysis) methodology, adapted for educational simulation.

RISK SCORING ALGORITHM

Risk Index = f(relative velocity, miss distance, object cross-section, atmospheric drag coefficient). Objects within 5km miss distance at relative velocity >1km/s are flagged CRITICAL.
